# GitHub publishing checklist

1. Open https://github.com/new
2. Repository name: `SWYNEX-App-Concept-and-Screen-Flow`
3. Description: `StudyFlow app concept, target user, six primary screens, and navigation flow for SWYNEX Task 1.`
4. Choose Public if a public link is appropriate for the submission.
5. Upload the contents of this folder, preserving the `docs` folder.
6. Commit message: `Add StudyFlow app concept and screen flow`
7. Confirm README renders on the repository front page.
8. Copy the repository URL into your LinkedIn caption.
9. Open both the GitHub link and LinkedIn post in an incognito/private window to check accessibility.

## Before submitting to SWYNEX
- Put the GitHub repository URL in “Task submission link”.
- Put the LinkedIn post URL in “LinkedIn explanation post link”.
- Check both links open without requesting permission.
- Submit only after the LinkedIn post is published.
