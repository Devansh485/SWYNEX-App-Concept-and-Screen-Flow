
# StudyFlow – Student Productivity App

StudyFlow is a student-focused productivity app concept designed to help students organize their tasks, plan study sessions, and track their progress.

## Features
- Interactive student dashboard
- Add, edit, and complete tasks
- Filter tasks
- Study schedule overview
- Progress tracking
- Responsive, mobile-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Explore the app and try the interactive features.

## Project Purpose
Created as part of an internship task to demonstrate app content planning, screen flow, UI design, and basic interactivity.
